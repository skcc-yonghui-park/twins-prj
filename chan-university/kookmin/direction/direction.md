# direction — 국민대 인문계열 학습 방향 및 전략 (박C*)

이 문서는 `chan-university/kookmin/` 폴더에서 작업할 때 따르는 **기준 문서**다. 사람이든 AI든 작업을 시작하기 전에 이 문서를 먼저 읽고, 아래 섹터별 프롬프트를 복사해 쓴다.

---

## 1. 수험생·시험 기준 정보

| 항목 | 내용 |
|---|---|
| 수험생 | 박C* (문과), 문서 본문에서는 **C* 군** |
| 대학·전형 | 국민대학교 논술전형 인문계열 (논술 100%, 내신 미반영) |
| 시험일 | **2026-12-05(토)**, 90분 |
| 시험 구성 | 국어 8문항(80점, 단답·단문 서술) + 수학 2문항(20점, 정답만 기입) |

| 수능최저 | 국·수·영·탐(상위 1과목) 중 2개 영역 합 6 이내, 한국사 응시 필수 |
| 수능 예상 등급(가채점) | 국어 4 · 수학 2 · 영어 3 · 사회·문화 4 · 세계사 2 → 수학+세계사=4로 충족 |
| 기준 보고서 | [result/2027학년도_국민대_논술가이드.md](../result/2027학년도_국민대_논술가이드.md) |

> 등급이나 시험 정보가 바뀌면 **이 표를 먼저 고친다.** 이후 프롬프트는 이 표를 기준으로 쓴다.

## 2. 폴더(섹터)별 역할

```
kookmin/
├── doc/         # 원천 데이터 저장소: 기출문제, 해설, 수험생 풀이 결과
│   ├── answer/  # 공식 해설지·정답 (있을 때)
│   └── solve/   # C* 군의 풀이 답안, 채점 결과 데이터
├── direction/   # 학습 방향·전략 기준 문서와 작업 프롬프트 (이 문서)
└── result/      # doc 기반 분석 보고서, 단기 전략 정의서, 작업 기록
```

### doc/ — 기출문제·풀이 결과 데이터 저장소
- **넣는 것:** 대학 가이드북·기출·모의논술 PDF, 공식 해설지(`doc/answer/`), C* 군이 직접 푼 답안과 채점 결과(`doc/solve/`).
- **규칙**
  - 원본 PDF는 **고치지 않는다.** 파일명은 받은 이름을 그대로 둔다.
  - 수험생 풀이 데이터는 `doc/solve/YYYY-MM-DD_<시험명>_풀이.md` 형식으로 저장한다. 문항별로 **제출 답 / 정답 / 득점 / 소요 시간 / 틀린 이유**를 표로 남긴다.
  - 해석이나 의견은 doc/에 쓰지 않는다. 분석은 모두 result/에 쓴다.

### result/ — 분석 보고서·단기 전략 정의서 저장소
- **넣는 것:** doc/ 자료를 **C* 군 수준에서** 분석한 보고서, 준비 전략, 단기 일정, 오답 분석.
- **파일 규칙**
  - 대학 가이드북 종합 분석: `<학년도>_국민대_논술가이드.md`
  - 개별 기출·모의고사 분석: `report-<원본 파일명>.md`
  - 풀이·채점 분석: `report-YYYY-MM-DD_<시험명>_오답분석.md`
  - 작업 기록: `result.md` (작업할 때마다 날짜순으로 한 줄 추가 + 요약 섹션)

### direction/ — 기준 문서
- 이 문서 하나로 관리한다. 수험생 정보, 학습 방향, 프롬프트가 바뀌면 여기서 고친다.

## 3. 학습 방향 (현재 기준)

1. **국어 찾아 쓰기 정확도가 1순위다.** 배점의 약 55%가 제시문에서 찾아 쓰는 단답이다. 조건(음절 수, 어절 수, "(가)에서 찾아")을 지키고 표기 그대로 옮기는 것이 점수다.
2. **수학 20점은 만점으로 고정한다.** 인문계 경쟁자 대비 확실한 우위다. 수학Ⅰ(지수·로그·삼각함수) 교과서 예제 수준을 검산까지 끝낸다.
3. **서술형(약 25점)은 "핵심어 2개 이상을 넣은 한 문장"으로 쓴다.** 꾸밈보다 제시문 개념어가 들어갔는지가 채점 기준이다.
4. **교재 우선순위:** 국민대 기출 > EBS 수능특강·수능완성(독서·문학) > 교과서. 다른 대학 약술형은 보지 않는다.
5. **목표:** 100점 환산 80점 내외 (수학 20 + 국어 단답 45 + 서술 15).

## 4. 섹터별 작업 프롬프트

아래 프롬프트의 `< >` 부분만 바꿔서 쓴다.

### P1. doc/ 자료 등록
```
chan-university/kookmin/doc/ 에 <파일명>을 추가했다.
direction/direction.md 규칙에 따라 다음을 해줘.
1. 자료 종류(가이드북/기출/모의논술/해설지/풀이 결과)를 판별하고 위치가 맞는지 확인
2. 해설지라면 doc/answer/로 옮길지 제안 (원본 파일명은 유지)
3. result/result.md "다음 할 일"에 이 자료로 할 분석 작업을 추가
```

### P2. 기출·가이드북 분석 보고서 (result/)
```
chan-university/kookmin/doc/<파일명>을 분석해서 result/<파일명 규칙>.md를 작성해줘.
- direction/direction.md의 수험생 정보와 학습 방향을 기준으로 C* 군 입장에서 정리
- 포함: 시험 개요, 문항별 정리(배점·제재·유형·정답), 출제 경향, 채점 기준에서 읽히는 요령
- 수학 문항은 직접 다시 풀어 정답을 검산하고 결과를 명시
- 해설의 오류·누락은 "해설에 대한 의견"에 근거와 함께 기록 (정답 영향 여부 표시)
- PDF 수식이 텍스트로 안 나오면 페이지를 이미지로 렌더링해서 읽기
```

### P3. C* 군 풀이 채점·오답 분석
```
doc/solve/<풀이 파일>은 C* 군이 <시험명>을 <시간>분 동안 푼 답안이다.
1. 가이드북 채점 기준대로 문항·소문항별 채점 (부분 점수 기준 그대로 적용)
2. 틀린 이유를 "조건 위반 / 다른 문단에서 찾음 / 유사어 선택 / 서술 핵심어 누락 / 계산 실수 / 시간 부족"으로 분류
3. 유형별 득점률(찾아 쓰기·서술·수학)과 목표(80점) 대비 차이
4. 결과를 result/report-<날짜>_<시험명>_오답분석.md로 저장하고 result.md에 기록
```

### P4. 단기 전략 정의서 (D-day 일정)
```
오늘은 <날짜>, 시험(12/5)까지 D-<n>이다.
result/의 최신 분석과 doc/solve/의 풀이 결과를 바탕으로 C* 군의 남은 기간 전략을 정의해줘.
- 하루 단위 일정표 (날짜·요일·할 일·분량)
- 약점 유형에 시간을 더 배정하고, 이미 안정된 영역(수학)은 유지 수준으로
- 시험장 시간 배분(90분)과 당일 체크리스트 포함
- 기존 가이드의 일정 섹션을 갱신하거나 별도 report로 저장
```

### P5. result.md 작업 기록
```
방금 한 작업을 chan-university/kookmin/result/result.md에 기록해줘.
- 상단 표에 날짜·작업·결과물 링크 한 줄 추가
- 날짜 섹션에 자료, 결과물, 핵심 결론 3~5개, 확인 사항 정리
- "다음 할 일" 체크리스트 갱신 (끝난 항목 체크)
```

### P6. 수험생 정보 갱신
```
C* 군의 <변경 내용: 예) 수능 실제 등급 국어 3, 수학 2 ...>이 확인됐다.
1. direction/direction.md 1장 표 갱신
2. 수능최저 충족 조합 재계산
3. 영향받는 result/ 문서(가이드 3장 등)를 고치고 result.md에 기록
```

## 5. 공통 작성 원칙

- **익명 표기:** 저장소가 public이다. 실명을 쓰지 않고 `박C*` / `C* 군`만 쓴다. 커밋 메시지도 같다.
- **근거 표시:** 가이드북 내용은 쪽수나 문항 번호를 함께 적는다. 추정은 "추정"이라고 밝힌다.
- **검산:** 수학 정답은 직접 풀어 확인한 뒤에만 "확인"이라고 쓴다.
- **2027 확인:** 가이드북의 기출은 2026학년도 시험이다. 고사 시간·입실 시각·고사장은 입학처 공지로 다시 확인할 항목으로 남긴다.
- **문체:** 짧은 평서문, 표 위주. 수식은 `$...$` LaTeX로 쓴다.
