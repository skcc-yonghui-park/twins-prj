# gachon — 가천대학교 자연계열 (박J*)

박J*의 2027학년도 가천대학교 논술전형 자연계열 준비 폴더입니다.

> 위치: [twins-prj](../../README.md) / [ju-university](../README.md) / gachon

## 요약

| 항목 | 내용 |
|---|---|
| 시험일 | **2026-12-01 (화)** 자연계열, 80분 (간호·바이오로직스·화공생명배터리는 11-30 월) |
| 구성 | **2027: 국어 5문항(단답) + 수학 8문항(풀이 서술)**, 각 10점 |
| 범위 | 수학Ⅰ·수학Ⅱ / 고1 국어. 전 문항 EBS 연계 |
| 채점 | 수학은 중간 단계마다 부분 점수, 동점자 1순위는 수학 성적 |
| 수능최저 | 1개 영역 3등급 이내 → 수학 2로 충족(가채점) |
