## 2. 폴더(섹터)별 역할

```
gachon/
├── doc/         # 원천 데이터 저장소: 가이드북, 모의고사, 해설, 수험생 풀이 결과
│   ├── answer/  # 공식 해설지 (모의고사 A형·B형 해설지)
│   └── solve/   # J* 군의 풀이 답안, 채점 결과 데이터
├── direction/   # 학습 방향·전략 기준 문서와 작업 프롬프트 (이 문서)
└── result/      # doc 기반 분석 보고서, 단기 전략 정의서, 작업 기록
```

### doc/ — 기출문제·풀이 결과 데이터 저장소
- **넣는 것:** 가이드북·기출·모의고사 PDF, 공식 해설지(`doc/answer/`), J* 군이 직접 푼 답안과 채점 결과(`doc/solve/`).
- **규칙**
  - 원본 PDF는 **고치지 않는다.** 파일명은 받은 이름을 그대로 둔다.
  - 문제지와 해설지는 분리한다. 해설지는 `doc/answer/`에 둔다.
  - 수험생 풀이 데이터는 `doc/solve/YYYY-MM-DD_<시험명>_풀이.md` 형식으로 저장한다. 문항별로 **제출 답 / 중간 단계 기재 여부 / 득점 / 소요 시간 / 틀린 이유**를 표로 남긴다.
  - 해석이나 의견은 doc/에 쓰지 않는다. 분석은 모두 result/에 쓴다.

### result/ — 분석 보고서·단기 전략 정의서 저장소
- **넣는 것:** doc/ 자료를 **J* 군 수준에서** 분석한 보고서, 풀이 과정, 준비 전략, 단기 일정, 오답 분석.
- **파일 규칙**
  - 가이드북·기출·모의고사 분석: `report-<원본 파일명>.md`
  - 풀이·채점 분석: `report-YYYY-MM-DD_<시험명>_오답분석.md`
  - 작업 기록: `result.md` (작업할 때마다 날짜순으로 한 줄 추가 + 요약 섹션)

### direction/ — 기준 문서
- 이 문서 하나로 관리한다. 수험생 정보, 학습 방향, 프롬프트가 바뀌면 여기서 고친다.

## 3. 학습 방향 (현재 기준)

1. **수학이 승부처다.** 2027은 수학 80점(8문항)/130점이고 동점자 1순위도 수학이다. 2026 기출 수학은 문항당 5분 수준이었다. 실수 없이 확보한다.
2. **중간 결과를 한 줄씩 따로 쓴다.** 최종 답은 대개 1점이고 함수식 확정, 경우 나누기 같은 중간 단계에 배점이 몰린다. 끝까지 못 풀어도 중간값을 남긴다. (국민대와 정반대이므로 혼동하지 않는다.)
3. **빈칸을 남기지 않는다.** 0점 문항 수가 동점자 기준이다.
4. **국어는 찾아 쓰기·조건 준수.** 첫/마지막 어절, 글자 수, 활용형 조건을 지키고 제시문 표현을 한 글자도 바꾸지 않고 옮긴다.
5. **교재 우선순위:** 가천대 기출·모의고사(A·B형) > EBS 수능특강·수능완성 수학Ⅰ·Ⅱ(극한으로 함수 결정, 삼차함수 개형, 적분으로 정의된 함수) > EBS 연계 문학 목록.
6. **답안 형식:** 검정 펜만, 수정은 취소선, 문항별 지정 영역 안에만 쓴다.

## 4. 섹터별 작업 프롬프트

아래 프롬프트의 `< >` 부분만 바꿔서 쓴다.

### P1. doc/ 자료 등록
```
ju-university/gachon/doc/ 에 <파일명>을 추가했다.
direction/direction.md 규칙에 따라 다음을 해줘.
1. 자료 종류(가이드북/기출/모의고사/해설지/풀이 결과)를 판별하고 위치가 맞는지 확인
2. 해설지라면 doc/answer/로 옮길지 제안 (원본 파일명은 유지)
3. result/result.md "다음 할 일"에 이 자료로 할 분석 작업을 추가
```

### P2. 기출·모의고사 분석 및 풀이 (result/)
```
ju-university/gachon/doc/<문제지>를 풀고 result/report-<원본 파일명>.md를 작성해줘.
- 해설지(doc/answer/)를 보기 전에 먼저 직접 풀고, 그 다음 해설지와 대조
- 수학은 채점 기준의 중간 단계가 드러나도록 풀이 과정을 단계별로 서술
- 국어는 정답과 허용 표현, 함정(정정된 내용, 조건) 정리
- 정답 요약표, 해설과 다른 점·해설 오류 기록, J* 군이 실수하기 쉬운 지점 표시
- PDF 수식이 텍스트로 안 나오면 페이지를 이미지로 렌더링해서 읽기
```

### P3. J* 군 풀이 채점·오답 분석
```
doc/solve/<풀이 파일>은 J* 군이 <시험명>을 <시간>분 동안 푼 답안이다.
1. 해설지 채점 기준표대로 중간 단계 배점까지 채점
2. 틀린 이유를 "개념 부족 / 계산 실수 / 중간값 미기재 / 경우 누락 / 조건 위반(국어) / 시간 부족"으로 분류
3. 국어·수학Ⅰ·수학Ⅱ별 득점률, 빈칸 문항 수, 만점 문항 수
4. 결과를 result/report-<날짜>_<시험명>_오답분석.md로 저장하고 result.md에 기록
```

### P4. 단기 전략 정의서 (D-day 일정)
```
오늘은 <날짜>, 가천대 시험(12/1, 지원 학과에 따라 11/30)까지 D-<n>이다. 이후 12/6 국민대 시험이 있다.
result/의 최신 분석과 doc/solve/의 풀이 결과를 바탕으로 J* 군의 남은 기간 전략을 정의해줘.
- 하루 단위 일정표 (날짜·요일·할 일·분량)
- 오답 유형이 많은 단원에 시간을 더 배정, 국민대 미적분은 하루 30분 이내
- 시험장 시간 배분(80분)과 답안 작성 체크리스트(검정 펜, 취소선, 답안 영역) 포함
- 별도 report로 저장하고 result.md에 기록
```

### P5. result.md 작업 기록
```
방금 한 작업을 ju-university/gachon/result/result.md에 기록해줘.
- 상단 표에 날짜·작업·결과물 링크 한 줄 추가
- 날짜 섹션에 자료, 결과물, 핵심 결론 3~5개, 확인 사항 정리
- "다음 할 일" 체크리스트 갱신 (끝난 항목 체크)
```

### P6. 수험생 정보 갱신
```
J* 군의 <변경 내용: 예) 국어 3, 물리학Ⅰ 4> 또는 가천대 2027 <수능최저/고사 시간>이 확인됐다.
1. direction/direction.md 1장 표 갱신
2. 수능최저 충족 여부 재계산
3. 영향받는 result/ 문서를 고치고 result.md에 기록
4. 국민대 direction(../../kookmin/direction/direction.md)의 같은 수험생 정보도 함께 갱신
```

## 5. 공통 작성 원칙

- **익명 표기:** 저장소가 public이다. 실명을 쓰지 않고 `박J*` / `J* 군`만 쓴다. 형제는 `C* 군`으로 쓴다. 커밋 메시지도 같다.
- **근거 표시:** 가이드북 내용은 쪽수나 문항 번호를 함께 적는다. 추정은 "추정"이라고 밝힌다.
- **검산:** 수학 정답은 직접 풀어 확인한 뒤에만 "확인"이라고 쓴다.
- **2027 확인:** 2027 가이드북(2026 기출)으로 문항 수·수능최저·시험일을 갱신했다. 채점 기준표는 공개되지 않았다. 고사 시간·입실 시각은 입학처 공지로 확인한다.
- **문체:** 짧은 평서문, 표 위주. 수식은 `$...$` LaTeX로 쓴다.
