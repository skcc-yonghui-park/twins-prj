# kookmin — 국민대학교 자연계열 (박J*)

박J*의 2027학년도 국민대학교 논술전형 자연계열 준비 폴더입니다.

> 위치: [twins-prj](../../README.md) / [ju-university](../README.md) / kookmin

## 요약

| 항목 | 내용 |
|---|---|
| 시험일 | **2026-12-06 (일)**, 90분 |
| 구성 | 수학 8문항(80점, 정답만 기입) + 국어 2문항(20점, 단답·짧은 서술) |
| 범위 | 수학(고1)·수학Ⅰ·수학Ⅱ·**미적분** / 국어·문학·독서 |
| 수능최저 | 2개 영역 합 6 이내(과탐만 인정) → 수학+영어=6으로 경계 충족(가채점) |
| 목표 | 100점 환산 77~85점 |
