# direction — 국민대 자연계열 학습 방향 및 전략 (박J*)

이 문서는 `ju-university/koomin/` 폴더에서 작업할 때 따르는 **기준 문서**다. 사람이든 AI든 작업을 시작하기 전에 이 문서를 먼저 읽고, 아래 섹터별 프롬프트를 복사해 쓴다.

## 2. 폴더(섹터)별 역할

```
koomin/
├── doc/         # 원천 데이터 저장소: 기출문제, 해설, 수험생 풀이 결과
│   ├── answer/  # 공식 해설지·정답 (있을 때)
│   └── solve/   # J* 군의 풀이 답안, 채점 결과 데이터
├── direction/   # 학습 방향·전략 기준 문서와 작업 프롬프트 (이 문서)
└── result/      # doc 기반 분석 보고서, 단기 전략 정의서, 작업 기록
```

### doc/ — 기출문제·풀이 결과 데이터 저장소
- **넣는 것:** 대학 가이드북·기출·모의논술 PDF, 공식 해설지(`doc/answer/`), J* 군이 직접 푼 답안과 채점 결과(`doc/solve/`).
- **규칙**
  - 원본 PDF는 **고치지 않는다.** 파일명은 받은 이름을 그대로 둔다.
  - 수험생 풀이 데이터는 `doc/solve/YYYY-MM-DD_<시험명>_풀이.md` 형식으로 저장한다. 소문항별로 **제출 답 / 정답 / 득점 / 소요 시간 / 틀린 이유**를 표로 남긴다.
  - 해석이나 의견은 doc/에 쓰지 않는다. 분석은 모두 result/에 쓴다.

### result/ — 분석 보고서·단기 전략 정의서 저장소
- **넣는 것:** doc/ 자료를 **J* 군 수준에서** 분석한 보고서, 준비 전략, 단기 일정, 오답 분석.
- **파일 규칙**
  - 대학 가이드북 종합 분석: `<학년도>_국민대_논술가이드.md`
  - 개별 기출·모의고사 분석: `report-<원본 파일명>.md`
  - 풀이·채점 분석: `report-YYYY-MM-DD_<시험명>_오답분석.md`
  - 작업 기록: `result.md` (작업할 때마다 날짜순으로 한 줄 추가 + 요약 섹션)

### direction/ — 기준 문서
- 이 문서 하나로 관리한다. 수험생 정보, 학습 방향, 프롬프트가 바뀌면 여기서 고친다.

## 3. 학습 방향 (현재 기준)

1. **11/30까지는 가천대 우선.** 수학Ⅰ·Ⅱ는 두 시험에 모두 쓰인다. 국민대 미적분은 하루 30분만 섞는다. ([가천대 direction](../../gachon/direction/direction.md) 참고)
2. **12/1부터 국민대 모드.** 미적분 우선순위: 정적분과 급수의 합(구분구적법) → 음함수 미분·접선 → 급수 → 입체 부피 → 삼각함수 극한. 고1 나머지정리도 점검한다.
3. **정답만 채점하므로 검산이 곧 점수다.** 소문항 (1)의 답이 (2)·(3)에 이어지는 연쇄 구조가 많다. 답을 조건식에 대입하고, 기약분수와 부호를 확인한다. 가천대식 "중간값 써 두기"는 국민대에서는 점수가 없다.
4. **국어 20점은 15분 안에 안정적으로.** 과학·기술 지문은 규칙(조건 → 결과)을 메모하고, 서술은 핵심어 2개 이상 넣은 한 문장으로 쓴다.
5. **교재 우선순위:** 국민대 기출 > 교과서 예제(미적분·수학Ⅱ) > EBS 수능특강·수능완성. 다른 대학 약술형은 보지 않는다.
6. **목표:** 100점 환산 77~85점 (수학 64 이상 + 국어 13 이상). 상위 학과는 85점 이상.

## 4. 섹터별 작업 프롬프트

아래 프롬프트의 `< >` 부분만 바꿔서 쓴다.

### P1. doc/ 자료 등록
```
ju-university/koomin/doc/ 에 <파일명>을 추가했다.
direction/direction.md 규칙에 따라 다음을 해줘.
1. 자료 종류(가이드북/기출/모의논술/해설지/풀이 결과)를 판별하고 위치가 맞는지 확인
2. 해설지라면 doc/answer/로 옮길지 제안 (원본 파일명은 유지)
3. result/result.md "다음 할 일"에 이 자료로 할 분석 작업을 추가
```

### P2. 기출·가이드북 분석 보고서 (result/)
```
ju-university/koomin/doc/<파일명>을 분석해서 result/<파일명 규칙>.md를 작성해줘.
- direction/direction.md의 수험생 정보와 학습 방향을 기준으로 J* 군 입장에서 정리
- 포함: 시험 개요, 문항별 정리(배점·과목·주제·정답), 과목별 비중(특히 미적분), 출제 경향, 채점 방식
- 수학 문항은 해설을 보기 전에 직접 풀고, 가이드북 정답과 대조한 결과를 명시
- 해설의 오타·근거 누락은 "해설에 대한 의견"에 기록 (정답 영향 여부 표시)
- PDF 수식이 텍스트로 안 나오면 페이지를 이미지로 렌더링해서 읽기
```

### P3. J* 군 풀이 채점·오답 분석
```
doc/solve/<풀이 파일>은 J* 군이 <시험명>을 <시간>분 동안 푼 답안이다.
1. 소문항별 정답 여부로 채점 (국민대 수학은 정답만 인정, 국어 서술은 채점 기준의 부분 점수 적용)
2. 틀린 이유를 "개념 부족 / 계산 실수 / 앞 소문항 연쇄 오답 / 문제 잘못 읽음 / 표기(부호·기약분수) / 시간 부족"으로 분류
3. 과목별(수학Ⅰ·수학Ⅱ·미적분·고1·국어) 득점률과 목표(77~85점) 대비 차이
4. 결과를 result/report-<날짜>_<시험명>_오답분석.md로 저장하고 result.md에 기록
```

### P4. 단기 전략 정의서 (D-day 일정)
```
오늘은 <날짜>, 국민대 시험(12/6)까지 D-<n>, 가천대 시험(11/30)까지 D-<m>이다.
result/의 최신 분석과 doc/solve/의 풀이 결과를 바탕으로 J* 군의 남은 기간 전략을 정의해줘.
- 하루 단위 일정표 (날짜·요일·할 일·분량), 가천대 일정과 겹치지 않게
- 오답 유형이 많은 과목·단원에 시간을 더 배정
- 시험장 시간 배분(90분: 국어 15 / 수학 60 / 검산 15 기준)과 당일 체크리스트 포함
- 기존 가이드의 일정 섹션을 갱신하거나 별도 report로 저장
```

### P5. result.md 작업 기록
```
방금 한 작업을 ju-university/koomin/result/result.md에 기록해줘.
- 상단 표에 날짜·작업·결과물 링크 한 줄 추가
- 날짜 섹션에 자료, 결과물, 핵심 결론 3~5개, 확인 사항 정리
- "다음 할 일" 체크리스트 갱신 (끝난 항목 체크)
```

### P6. 수험생 정보 갱신
```
J* 군의 <변경 내용: 예) 국어 3, 물리학Ⅰ 4, 수학 선택과목 미적분>이 확인됐다.
1. direction/direction.md 1장 표 갱신
2. 수능최저 충족 조합 재계산 (과탐만 인정, 사탐 불인정)
3. 영향받는 result/ 문서(가이드 3장·7장 등)를 고치고 result.md에 기록
4. 가천대 direction의 같은 정보도 함께 갱신
```

## 5. 공통 작성 원칙

- **익명 표기:** 저장소가 public이다. 실명을 쓰지 않고 `박J*` / `J* 군`만 쓴다. 형제는 `C* 군`으로 쓴다. 커밋 메시지도 같다.
- **근거 표시:** 가이드북 내용은 쪽수나 문항 번호를 함께 적는다. 추정은 "추정"이라고 밝힌다.
- **검산:** 수학 정답은 직접 풀어 확인한 뒤에만 "확인"이라고 쓴다.
- **2027 확인:** 가이드북의 기출은 2026학년도 시험이다. 고사 시간·입실 시각·고사장은 입학처 공지로 다시 확인할 항목으로 남긴다.
- **문체:** 짧은 평서문, 표 위주. 수식은 `$...$` LaTeX로 쓴다.
